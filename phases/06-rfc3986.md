# Phase 06 — RFC 3986 URI

**Depends on:** 01, 05  
**Unlocks:** 08

## Goal

Parse, serialize, and resolve URI-references per RFC 3986 (and IRI characters per RFC 3987 when `ParseOptions.iri` is true). **No** WHATWG recoveries.

## Specs to read

- [`specs/02-data-model.md`](../specs/02-data-model.md) — `Uri` record
- [`specs/03-parsing.md`](../specs/03-parsing.md) — `rfc3986` profile
- [`specs/07-serialization-and-resolution.md`](../specs/07-serialization-and-resolution.md) — recomposition, §5, normalization
- RFC 3986 §§3, 5, 6.2.2, Appendix A and B
- RFC 3987 (when `iri=true`)

## Create


Define `Uri` here (or `src/heat_url/uri.mojo` if the file grows). Do not put WHATWG `Url` in this file.

## Implement

- Split using the Appendix B five-component structure as a **pointer scan** (not a regex engine requirement)
- Authority → userinfo / `parse_host_rfc3986` / port (`*DIGIT`; do not coerce >65535 into `UInt16` silently)
- `has_authority` distinguishes `foo:/bar` vs `foo://bar`
- Lowercase **scheme** only at parse; do not IDNA-convert `reg-name` unless `options.idna_host`
- `https:example.org` **fails** or parses as scheme `https` + path `example.org` according to ABNF (`hier-part` without `//` is `path-rootless`). Do **not** insert `//`
- No `\` → `/`
- Relative resolution RFC 3986 §5.2 when input is relative-ref **and** base is provided
- Serialize §5.3; IPv6 in `[]`; zone `%25`
- `normalize_syntax` option applies §6.2.2 only when set (default off)

IRI: if `iri=false`, non-ASCII outside percent-encoding fails. If true, allow RFC 3987 characters in non-scheme components.

Honor `check_input_length` / authority length cap. Error messages through `redact_userinfo`.

## Tests (minimum)

- Appendix B: `http://www.ics.uci.edu/pub/ietf/uri/#Related` component split
- RFC 3986 §5.4 relative resolution examples (normal and abnormal)
- `urn:isbn:0451450523` — no authority, path/rootless
- `HTTP://Example.COM/foo` — scheme lowercased; host case preserved unless normalize
- `https:example.org` does not become `https://example.org/`
- IPv6 and zone ID round-trip when enabled
- Non-decimal port stays text or fails on UInt16 coerce; pick the spec’s RFC behavior and test it
